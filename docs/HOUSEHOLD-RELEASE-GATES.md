# Household release gates

- [ ] Identity sign-in, verified email, MFA and recovery
- [ ] Server-side household membership verification on every operation
- [ ] Database RLS with non-bypass application role and audited privileged migration role
- [ ] One-time expiring invitation flow and revocation
- [ ] Atomic split-sum checks; settlement and transfer invariant tests
- [ ] Adversarial cross-tenant authorization tests (including IDOR and removed members)
- [ ] Unit tests for split rounding and accounting totals
- [ ] Encrypted backup/restore tested; secrets management and TLS configured
- [ ] Independent security review before any real financial data
