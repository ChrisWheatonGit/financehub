# FinanceHub v1.5 — Calm Appearance + Profile

- Settings > Appearance: six curated calm palettes, works with Light, Dark, and System modes. Preferences persist in browser localStorage.
- Click the avatar in the upper-right corner to open **Edit profile** or **Appearance settings**.
- My Profile: display name, occupation, employer, optional region, biography, and 12 avatar icons; save explicitly.
- This feature is browser-only demo personalization, **not** authenticated user profile persistence. Do not enter private information.
- Existing dashboard, transactions, household proof-of-concept, and APIs retained from v1.4.
- Test palette switching for each mode, reload persistence, profile edit/save and navigation, responsive layout, `npm run build`, and regression tests.
- Future: server-side per-account preferences, schema validation, user ownership, accessibility review, complete replacement of legacy hard-coded graph colors, and independent security review.
